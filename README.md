# DAI QA Loader v1.1.4

Versión con selección de facturas.

## Incluye

- QA
- MOCKDEVNOKIT
- URL manual
- Login mock
- Registro IC04
- Carátula completa hasta Facturas
- Opción: Con facturas / Sin facturas
- Avance a Ítems

## Uso

1. Conectarse a VPN.
2. Ejecutar `Ejecutar.bat`.
3. Seleccionar ambiente.
4. Seleccionar IC04.
5. Seleccionar Caso Feliz.
6. Seleccionar Con facturas o Sin facturas.
7. Seleccionar Posicion Arancelaria.
8. Ingresar sufijos manualmente (SOON)
9. Preguntas de items.
10. Ingreso de Documentos de Transporte en el inicio de la tool.
11. Ingreso de CERTIPAC-ROM en el inicio de la tool.
